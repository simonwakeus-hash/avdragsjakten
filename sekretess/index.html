Sekretess

På Avdragsjakten vet vi att deklaration kan kännas privat. Därför är tjänsten byggd så att du ska kunna använda den utan att behöva lita på någon annan än din egen webbläsare.

Din data lämnar aldrig din enhet

När du laddar upp din deklaration eller fyller i uppgifter analyseras filen direkt i din webbläsare. Det innebär att:

  • vi kan inte se den
  • vi lagrar inte innehållet
  • inget skickas till någon server

Du behåller full kontroll — informationen ligger kvar hos dig.

Ingen åtkomst för oss (eller någon annan)

Eftersom beräkningen sker lokalt i din webbläsare har vi ingen teknisk möjlighet att öppna eller läsa dina uppgifter.

Det finns ingen intern person, extern leverantör eller partner som kan se din deklaration via Avdragsjakten.

Vi säljer inget. Vi delar inget.

Dina uppgifter används enbart för att räkna ut dina avdrag, och den processen sker lokalt hos dig. Vi delar ingenting vidare — varken med Skatteverket, annonsörer eller någon annan.

Vad vi faktiskt samlar in

För att förbättra tjänsten samlar vi endast in anonymiserad statistik, till exempel:

  • hur många som använder tjänsten
  • vilka steg som används mest
  • var användare fastnar eller överger flödet

Det hjälper oss att förbättra upplevelsen — men det kan aldrig kopplas till dig som person eller din deklaration. Vi lagrar inga filer, inga personuppgifter och inga deklarationsdata.

Krypterad anslutning

Avdragsjakten körs via krypterad anslutning (HTTPS/TLS), vilket skyddar din kommunikation när du använder sidan.

Kort sagt

Du delar inte din deklaration med oss. Du låter din webbläsare bearbeta den åt dig — lokalt, privat och utan insyn.

Vi använder bara anonym trafikdata för att förstå hur tjänsten används och hur vi kan göra den bättre.

Det är därför Avdragsjakten kan hjälpa dig — utan att behöva se någonting.
